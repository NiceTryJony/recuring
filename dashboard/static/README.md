# dashboard/static/ — CSS и JS

Отдаются через `assets.py`: файл минифицируется, в имя добавляется хеш (`base.<хеш>.css`), кэш — на год.
Правка файла сама меняет URL. Подключать новый файл: `publish("name.css")` / `stylesheets("name.css")`.

| Файл | Где грузится | Зачем |
|---|---|---|
| `base.css` | везде | переменные темы («тёплая бумага» / тёплый графит, один акцент; + тема Telegram `--tg-*`), шрифты, навбар, таббар, карточки, кнопки, формы, поля с плавающей подписью, тост, переход между страницами, шторка «Производительность» (`.perf-*`) и уровень `.min` (без единой анимации) |
| `manrope-*.woff2`, `source-serif-4-*-700.woff2` | через `@font-face` в `base.css` | свои шрифты (Manrope — текст, Source Serif 4 — крупные заголовки и цифры), по три подмножества (latin / cyrillic / latin-ext) с `unicode-range`; отдаёт `assets.publish_font`, версия шрифта — в имени файла |
| `tasks.css` | страница задач | карточка задачи, чекбокс-«капля», подзадачи, график, рамка `.chart-lazy` |
| `share.css` | экран «Общая задача» | карточка с превью задачи |
| `login.css` | вход | карточка с паролем |
| `history.css`, `templates.css` | история, шаблоны | точечные стили страниц |
| `dashboard.js` | страница задач и «Общая задача» (все устройства) | Mini App (тема, кнопки Назад/Main), **действия без перезагрузки** (оптимистичный UI, FLIP-анимация, откат + тост), ленивые карточки, лайтбокс фото, подгрузка графика, «Поделиться» |
| `fx.css`, `fx.js` | **только мощный десктоп** (`html.fx`) | статичная сетка + подсветка линий под курсором, пятна света и рамка карточек, наклон карточек, «магнитная» кнопка «+», волна и частицы при выполнении, конфетти при закрытии последней задачи дня, палитра команд (`Ctrl/Cmd+K`), горячие клавиши (`n j k x ?`) |

## Правила
- Анимировать только `transform` и `opacity`; на слабых телефонах (нет класса `.mid`) эффекты минимальны, уважать `prefers-reduced-motion`.
- В `dashboard.js` комментарии `//` в начале строки вырезаются минификатором; код — в стиле ES5 (без сборщика).
- Цвета и отступы — только через переменные из `base.css`.
- Скрытое начальное состояние (`.rv`) ставит только `fx.js`: не загрузился скрипт — всё видно.
- Указатель в `fx.js` — один `pointermove` и один `requestAnimationFrame` на кадр, только `transform`/`opacity`. Не писать `--mx`/`--my` и любые CSS-переменные на `<html>`/`<body>` (пересчёт стилей всей страницы на каждое движение) и не звать `getBoundingClientRect` на каждое движение: размеры берутся из кэша `rects`.
- Классы `.sp` (заголовок, `splitTitle`) и `.fx-sp` / `.fx-ring` (пятна света карточек) — разные; не переиспользовать имена между эффектами.
- Телефон: график и счётчики не анимируются, тяжёлое (тени, blur, наклон, сетка) — только под `.mid`/`.fx`. Ручной выбор уровня в шторке сохраняется в `localStorage` (`perf`: auto / full / lite / min).
